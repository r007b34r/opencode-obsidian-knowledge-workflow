# Weekly Synthesis Trigger Evals

## Should trigger
- "Synthesize this week/month/period of notes."
- "Find the emerging thesis, contradictions, gaps, next action, and next question."
- "What is the meaning of recent notes over this time window?"

## Should not trigger
- Link-only review: use connection-review.
- Inbox routing: use inbox-triage.
- Project status reporting without meaning-making: do not use this skill.

## Near misses
- "List notes from this week" is search/list, not synthesis.
- "Summarize one article" is not weekly synthesis.

## Pass criteria
- Exactly one next action.
- Exactly one next question.
- Thesis is evidence-backed, not a generic summary.
