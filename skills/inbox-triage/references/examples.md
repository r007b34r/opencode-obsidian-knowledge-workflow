# Inbox Triage Examples

## Good item decision
```markdown
- [[Inbox/foo]] -> promote
  Evidence: contains reusable claim and clear future retrieval value.
  Next step: run note-promotion only after confirming target note type.
```

## Bad item decision
```markdown
- [[Inbox/foo]] -> promote because it seems interesting.
```

Problem: no evidence, no routing boundary, no next action.

## Route definitions
- keep: useful but not yet worth promotion.
- promote: stable reusable idea/reference/question/contradiction.
- project: tied to an active outcome or deliverable.
- archive: low future value or already captured elsewhere.
- deep-read: source requires careful extraction before routing.
