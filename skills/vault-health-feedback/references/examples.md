# Vault Health Feedback Examples

## Good finding
```markdown
- Risk: capture is outpacing distillation.
  Evidence: many inbox notes lack next actions, while few promoted notes have backlinks or evals.
  Repair: add a weekly promotion gate before adding new categories.
```

## Bad finding
```markdown
- The vault has too many notes; delete some.
```

## Health dimensions
- Cognitive return.
- Retrieval reliability.
- Workflow friction.
- Promotion quality.
- Maintenance burden.
