# Vault Health Feedback Trigger Evals

## Should trigger
- "Is my vault becoming a passive archive?"
- "Diagnose workflow health, friction, cognitive return, or risk signals."
- "Give bounded feedback on the knowledge system before cleanup."

## Should not trigger
- Direct restructuring or batch cleanup without diagnosis.
- Link-only review: use connection-review.
- Weekly meaning-making: use weekly-synthesis.

## Near misses
- "Move these files" is organization work, not health feedback.
- "Find duplicates" is search/cleanup unless framed as workflow health.

## Pass criteria
- Bounded sample, not whole-vault sprawl.
- One highest-leverage repair.
- Avoid vanity metrics as the main conclusion.
