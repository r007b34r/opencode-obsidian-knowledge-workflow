# Note Promotion Examples

## Good promotion decision
```markdown
Type: contradiction note
Title: Automation can reduce reflection quality
Source evidence: weekly synthesis recommends automation; vault-health note warns passive archive risk.
Why reusable: applies across workflow design decisions.
Integration: link to automation, weekly review, and vault health notes.
```

## Bad promotion decision
```markdown
Promote because it is useful.
```

## Promotion types
- reference
- idea
- project
- topic
- synthesis
- contradiction
- question
