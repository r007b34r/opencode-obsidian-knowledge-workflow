# Connection Review Examples

## Good link suggestion
```markdown
- Link [[A]] -> [[B]]
  Evidence: both describe tool safety constraints, but A covers host failures while B covers workflow rules.
  Confidence: medium
```

## Bad link suggestion
```markdown
- Link [[A]] -> [[B]] because both mention productivity.
```

## Good contradiction
```markdown
- Tension: [[A]] says automate all recurring review; [[B]] warns against passive archive automation.
  Why meaningful: automation could reduce reflection quality.
  Follow-up: create a question note on review automation boundaries.
```
